# langLSRW 难度等级（CEFR）

最后更新：2026-10-31
定级规则版本：`cefr-rules/2`

本文档是 langLSRW 所有难度判断的统一标准。句库例句、以后的等级句库、AI 生成的学习文章和复习材料，以及学习者自身水平的设定，都使用这里定义的六个等级。规则变化时先改本文档并升级版本号，再改数据、代码和测试。

## 1. 六个等级

等级采用欧洲语言共同参考框架（CEFR）的 A1–C2。界面直接显示 `A1`、`A2` 等代号，悬停说明用下表的中文名称和一句话描述。

| 代号 | 中文名称 | 学习者能做什么（本项目的简述） | 大致词汇量 | 大致对照（非官方换算） |
|---|---|---|---|---|
| A1 | 入门 | 听懂并说出最简单的日常短句：问候、自我介绍、点单、问价 | 500–1,000 | 小学到初一 |
| A2 | 初级 | 应付常见生活场合：购物、问路、订票、描述过去的经历 | 1,000–2,000 | 中考 |
| B1 | 中级 | 独立处理旅行和工作中的大部分情况，能说明理由、表达意见 | 2,000–3,500 | 高考、四级 |
| B2 | 中高级 | 流利地讨论熟悉的话题，听懂一般新闻和讲座的主要内容 | 3,500–6,000 | 六级、考研、雅思 5.5–6.5、托福 72–94 |
| C1 | 高级 | 读懂较长较难的文章，灵活地用于学习和工作，表达含蓄语气 | 6,000–10,000 | 雅思 7–8、托福 95–113 |
| C2 | 精通 | 理解几乎所有听到和读到的内容，辨别细微的意思差别 | 10,000 以上 | 雅思 8.5 以上、托福 114 以上 |

“大致对照”只用于帮助理解，不是官方换算，也不写进数据。

## 2. 句子定级规则

每句从**词汇**、**句法**、**句长**三方面判断，最终等级取三者中最高的一项，但句长只作参考：句长最多让等级比词汇和句法的较高者再高一级。

### 2.1 词汇

以句中**最难的那个词**定级。脚本用项目内置的 ECDICT 词典判断：先把词形还原为原形（用词典的 `exchange` 字段；`went`、`was` 这类不规则形式在词典里没有单独的词频，从原形的变化表反查），再分别按考试标签和词频得出等级，**取两者中较低（较容易）的一个**，因为常用词即使出现在高级考试词表中也不难。

按考试标签（ECDICT `tag` 字段）：

| 标签 | 等级 |
|---|---|
| `zk`（中考） | A2 |
| `gk`（高考）、`cet4`（四级） | B1 |
| `cet6`（六级）、`ky`（考研） | B2 |
| `ielts`（雅思）、`toefl`（托福） | C1 |
| `gre` | C2 |

按词频（ECDICT 的美式语料排名 `frq` 和英式语料排名 `bnc`，取排名靠前的一个）：

| 词频排名 | 等级 |
|---|---|
| 1–1,000 | A1 |
| 1,001–2,000 | A2 |
| 2,001–3,500 | B1 |
| 3,501–6,000 | B2 |
| 6,001–10,000 | C1 |
| 10,000 以后，或词典中没有 | C2 |

词典没有专门的入门词表，最低一档是中考词表，而 please、coffee、milk 这类入门词的词频排名多在 1,000 以后。因此**中考词表中词频排名在 3,500 以内的词算 A1**。

**功能词一律算 A1**：代词（包括 `mine`、`yours`）、`be`、`do`、`have` 的各种形式、情态动词、冠词、常用介词和连词。这些词在词典里的数据常被同形词干扰，例如 `mine` 会被当成“矿”，`does` 会被当成 `doe` 的复数。

以下内容不参与词汇定级：

- 人名、地名、品牌名和数字。
- 一词多义时按句中的意思定级；脚本只能按词典的首要意思判断，遇到同形词以人工复核为准。
- 场景专用词：在该场景里必须用、本身就是学习目标的词，例如咖啡店的 `cappuccino`、邮局的 `parcel`。是否属于场景专用词由人工判断。
- 常见缩写和网络用语（如 `BTW`、`ASAP`）按含义难度人工定级。

固定短语和习语按整体意思定级，不按单个词。例如 `under the weather` 每个词都简单，整体仍定为 B2。

### 2.2 句法

以句中**最难的结构**定级。

| 等级 | 典型结构 |
|---|---|
| A1 | `be` 和 `have` 的基本用法、一般现在时、现在进行时、祈使句、`can` 表示能力、简单疑问句、固定寒暄语 |
| A2 | 一般过去时、`will` 和 `be going to`、比较级和最高级、`Can I / Could you` 礼貌请求、`and / but / because / so` 连接的简单句、`there be` |
| B1 | 现在完成时、过去进行时、常见被动语态、第一和第二条件句、宾语从句、`that / who / which` 定语从句、间接疑问句、`used to`、动名词和不定式的常见搭配 |
| B2 | 过去完成时、完成进行时、第三条件句、各时态的被动语态、情态动词表推测（`must have been`）、非限定性定语从句、分词短语、间接引语、`wish / if only` |
| C1 | 倒装、强调句、混合条件句、多种虚拟语气、名词化表达、独立主格、委婉和含蓄的语气 |
| C2 | 文学性和修辞性结构、少见的倒装、大量省略、依赖言外之意的表达 |

### 2.3 句长

按英文单词数计算，缩写形式（如 `I'm`）算一个词。

| 词数 | 参考等级 |
|---|---|
| 1–6 | A1 |
| 7–10 | A2 |
| 11–15 | B1 |
| 16–22 | B2 |
| 23–30 | C1 |
| 31 以上 | C2 |

### 2.4 判定流程

1. 编写例句时，按 2.1–2.3 人工标出等级。
2. 运行 `npm run check:cefr`（即 `python tools/check-cefr.py`），检查脚本按词汇和句长计算参考等级，并列出两类句子：人工等级比参考等级低的，以及人工等级比参考等级高两级以上的。加 `-v` 列出每句的核对明细。场景专用词表写在脚本的 `EXEMPT` 中，新增场景时一并补充。
3. 对脚本标出的句子逐句人工复核，修改等级或改写句子。脚本列出的句子不一定要改：习语、短语动词和一词多义按 2.1 整体定级，常比脚本参考等级高；脚本把 `canceled`、`traveling`、`favorite`、`emails` 这类美式拼写或复数误判为难词。人工复核后保留原等级的句子，下次运行仍会列出。
4. 全程不调用 AI。以后若用 AI 生成材料，生成结果同样经过这套规则检查。

### 2.5 常见判定惯例

以下是日常频道定级时对 2.1–2.3 的统一应用，后续材料照此执行：

- 7 个词以上的句子不标 A1，11 个词以上的不标 A2（句长最多抬高一级，见 2.3）。
- 字面意思的基础短语动词（`sit down`、`come in`、`pick up` 表示拿起）按单词定级；意思引申的短语动词和习语（`go easy on`、`grow on`、`pencil in`、`work for you` 表示方便）至少 B1。
- 现在完成时为 A2 起点；完成进行时、完成时的被动、`have / get something done`、情态动词加完成时为 B2。
- `online`、`discount`、`sometime` 等词频不低但考试标签较高的词，统一按 B1。
- 场景专用词不抬高等级，但句子仍按句法和句长定级，例如 `There's a stain here.` 定为 A2 而不是 A1。

## 3. 数据格式

例句用可选字段 `cefr` 记录等级，取值只能是 `"A1"`、`"A2"`、`"B1"`、`"B2"`、`"C1"`、`"C2"`：

```json
{ "id": "daily.food.restaurant.bill_tip.001", "en": "Check, please.", "zh": "买单。", "cefr": "A1" }
```

- 没有 `cefr` 字段表示“未定级”。加载器不猜测等级，界面也不显示。
- 含有定级例句的数据文件，在文件顶层记录 `"cefrRules": "cefr-rules/2"`，说明按哪个版本的规则定级。规则升级后，旧数据保留原版本号，重新定级是一次明确的操作，不自动改写旧数据。
- 等级名称、说明和对照只写在本文档和代码常量中，不在每个数据文件里重复。
- **序号和等级分开**：例句编号末尾的序号一经给出永不改变；等级只写在 `cefr` 字段里，改等级只改这个字段。显示时先按等级由易到难排列，同一等级内按添加的先后排列，未定级的句子排在最后。
- 一个话题首次成批写入时，先按等级由易到难排好，再依次编号 `.001`、`.002`……；以后追加的句子接着往后编号，由加载器按等级排到对应位置。

## 4. 各类材料的等级范围

| 材料 | 主要范围 |
|---|---|
| 日常频道 | A1–B2 |
| 新闻频道 | B1–C1 |
| 纪录片频道 | B1–C2 |
| 歌词频道 | A2–C1 |
| 演讲频道 | B2–C2 |
| 语法句库 | 按语法点本身的难度，见 2.2 |

**选句以常用为准，等级只是如实标注，不设配额。** 等级用来排序和筛选，回答“这句话有多难”，而不是“每个等级要凑够几句”。日常场景里简单句本来就多，日常话题以 A1–B1 为主是正常的；不为凑高等级而写真实场合中很少说的句子。

判断一句话是否常用：

1. 在这个场景里，服务员、店员或顾客会反复说这句话，而不是偶尔才说一次。
2. 每句解决一件具体的事，例如问推荐、提要求、改主意、确认点单。优先收入不同的需要，同一个需要不重复堆砌。
3. 双方的话都要有：既能听懂对方，也能自己开口。
4. 同一个意思只收真实常用的几种说法，例如要结账时 *Check, please.* 和 *Could we have the check?* 都常用就都收，生造的委婉说法不收。
5. 本频道其他话题已有的句子和需要不再重复收入。只差 please、now、称呼或一两个词的近似句也算重复，例如 *Can you help me?* 和 *Can you help me, please?* 只收一句。

**频道句库统一使用美式英语。** 拼写、用词、说法和场景细节都按美国习惯：canceled、mom、vacation、apartment、elevator、line（排队）、restroom、gas、parking lot、check（餐厅结账）、fill out、on the weekend；少用 *Shall we…?*，改用 *Should we…?*、*How about…?*；重量、长度、距离、温度用磅、英寸、英里、华氏度；不写英国特有的制度和设施，如 GP、council tax、double yellow lines。*Would you mind…*、*I've got*、*lovely* 这类美式也常用的说法照常使用。

每个话题以 20 句以上为目标，但不为凑数而硬写；常用句子确实不足 20 句的话题如实保留，最少 15 句，不足 15 句时与相邻话题合并。超过 50 句时拆分成几个话题。每个场景的话题数按实际需要定（通常 2–6 个），不为整齐凑数。付款、道谢、约人这类通用说法只放在一个场景，其他场景只写本场景特有的说法。

首次写入时，同一等级内按常用程度排列，最常用的在前。

样本：`daily.food.restaurant.ordering`（点菜与问推荐）。

## 5. 界面约定

- 等级标签直接显示 `A1`–`C2`。
- 等级标签和等级筛选控件的 `title` 说明使用“代号 + 中文名称 + 一句话描述”，例如“A2 初级：应付常见生活场合，如购物、问路、订票”。
- 未定级的句子不显示等级标签。按等级筛选时，未定级的句子单独归为“未定级”。
