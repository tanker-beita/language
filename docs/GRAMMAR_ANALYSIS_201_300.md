## 201. She usually walks to work.

她通常步行上班。

句型：主语 + 谓语 + 状语

- 主语：She（人称代词）
- 状语：usually（副词）
- 谓语：walks（动词（一般现在时））
- 状语：to work.（介词短语）
  - 其他：to（介词）
  - 宾语：work.（介词宾语（名词短语））

- usually 是频率副词，位于实义动词 walks 前。
