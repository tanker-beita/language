## 301. The baby smiled.

宝宝笑了。

句型：主语 + 谓语

- 主语：The baby（名词短语）
  - 定语：The（冠词）
  - 中心语：baby（名词）
- 谓语：smiled.（动词（一般过去时））

- smiled 是不及物动词；The baby 是主语，本句是主谓结构。
