## 401. He works in a library.

他在图书馆工作。

句型：主语 + 谓语 + 状语

- 主语：He（人称代词）
- 谓语：works（动词（一般现在时））
- 状语：in a library.（介词短语）
  - 其他：in（介词）
  - 宾语：a library.（介词宾语（名词短语））
    - 定语：a（冠词）
    - 中心语：library（名词）

- He 是第三人称单数主语，谓语用 works；in a library 作地点状语。

## 499. Will you be using the car this evening?

  - 中心语：using（现在分词）
- 宾语：the car（直接宾语（名词短语））
  - 定语：the（冠词）
  - 中心语：car（名词）
- 状语：this evening?（时间名词短语）
  - 定语：this（限定词）
  - 中心语：evening（名词）

- Will 提到主语前形成将来进行时问句，和 be using 共同构成谓语；可用于询问对方的用车安排。
- 谓语组成被主语或 not 隔开；当前连续片段格式分别保留各部分，不能关联为一个谓语节点，因此标记格式限制，完整语法关系见前述说明。
